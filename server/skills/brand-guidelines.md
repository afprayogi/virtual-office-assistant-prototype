# Anthropic Brand Styling

## Colors
**Main:**
- Dark: `#141413` — primary text / dark backgrounds
- Light: `#faf9f5` — light backgrounds / text on dark
- Mid Gray: `#b0aea5` — secondary elements
- Light Gray: `#e8e6dc` — subtle backgrounds

**Accent:**
- Orange: `#d97757` — primary accent
- Blue: `#6a9bcc` — secondary accent
- Green: `#788c5d` — tertiary accent

## Typography
- Headings: Poppins (fallback Arial)
- Body: Lora (fallback Georgia)
- Headings 24pt+: Poppins; body text: Lora
- Smart color selection based on background; preserve text hierarchy.

## Shape & Accents
- Non-text shapes use accent colors, cycling orange → blue → green.
