# Doc Co-Authoring Workflow

This skill provides a structured workflow for guiding users through collaborative document creation. Act as an active guide, walking users through three stages: Context Gathering, Refinement & Structure, and Reader Testing.

## Stage 1: Context Gathering
Ask: what type of document, primary audience, desired impact, template? Then let the user dump all context. Ask 5-10 clarifying questions.

## Stage 2: Refinement & Structure
Build the document section by section. For each section: ask clarifying questions, brainstorm 5-20 options, user curates (keep/remove/combine), check gaps, draft, refine with surgical edits. Never reprint the whole doc; use targeted edits.

## Stage 3: Reader Testing
Predict 5-10 reader questions, test the doc with a fresh instance, check ambiguity/assumptions/contradictions, then fix gaps.

## Final Review
Re-read the full doc for flow, consistency, redundancy, and filler. Recommend a final human read-through and verifying facts.

Tone: direct, procedural, explain rationale briefly, give user agency.
