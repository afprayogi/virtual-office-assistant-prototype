## When to use this skill
Use for internal communications such as:
- 3P updates (Progress, Plans, Problems)
- Company newsletters
- FAQ responses
- Status reports
- Leadership updates
- Project updates
- Incident reports

## How to use this skill

1. **Identify the communication type** from the request.
2. **Follow the matching format** from the repo's `examples/` directory:
   - `examples/3p-updates.md` — Progress/Plans/Problems team updates
   - `examples/company-newsletter.md` — company-wide newsletters
   - `examples/faq-answers.md` — FAQ answers
   - `examples/general-comms.md` — anything else
3. **Follow the specific instructions** in that file for formatting, tone, and content gathering.

If the type doesn't match any guideline, ask for clarification about the desired format.
