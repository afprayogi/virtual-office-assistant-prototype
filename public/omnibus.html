OmniRoute punya endpoint kuota/usage sendiri (/api/usage, dll) di luar API /v1, tapi butuh "token manajemen" terpisah (bukan API key chat). Isi di Pengaturan bila punya, lalu cek di sini.
Routing
OmniRoute mendukung ±19 strategi routing (priority queue, load balancing, cost/latency optimized, fusion/panel voting, dsb). Pilih di topbar — dikirim sebagai field omniroute_strategy & header X-OmniRoute-Routing-Strategy. Dukungan tergantung versi/konfigurasi server Anda.
Kompresi token
Pipeline kompresi OmniRoute (session dedup, RTK filtering, Caveman prose, LLMLingua-2, dst — 12 engine total) diaktifkan lewat toggle "Kompresi". Kode & JSON tetap byte-perfect.
Resiliensi
Circuit breaker, cooldown koneksi, dan lockout per-model ditangani otomatis oleh server OmniRoute saat sebuah provider gagal/limit — tidak perlu logic tambahan di klien ini.
Endpoint default
http://localhost:20128/v1 — jalankan npx omniroute@latest lalu atur Base URL di Pengaturan bila berbeda.
Provider butuh API key/login?
Buka tab "Provider" lalu tekan "Tes semua provider" — tiap grup provider (mis. aug/*, tllm/*, oc/*) dicek sekali dan ditandai 🟢/🔴 beserta alasannya. Kalau 🔴, biasanya provider itu perlu dihubungkan (API key/login/CLI) langsung di dashboard bawaan OmniRoute — bukan di aplikasi chat ini, karena kredensial provider disimpan & dikelola oleh OmniRoute sendiri.

System prompt (percakapan ini)

Grup chat baru

Ketik @nama di pesan selalu bisa nargetin satu anggota tertentu, apapun mode-nya di sini.
Tiap putaran, semua anggota aktif bicara satu per satu membahas topik yang kamu kirim — seperti rapat meja bundar. Setelah putaran terakhir, sebuah model (default "auto") membuat kesimpulan diskusinya secara otomatis.
Model dengan nama yang sama (lewat provider/jalur berbeda) dianggap satu dulu, baru diuji koneksinya satu per satu — jadi tidak menguji hal yang sama berkali-kali. Semua yang benar-benar terhubung dianalisis (kemampuan reasoning, ukuran konteks, kecepatan respons), diurutkan dari yang terbaik, baru diambil sejumlah target. Kalau yang terhubung lebih sedikit dari target, yang terbaik dari yang ada tetap dipakai.
Pernah dikeluarkan otomatis (tidak merespons saat itu):
Tiap anggota membalas satu per satu secara berurutan dan bisa melihat balasan anggota lain sebelum gilirannya — supaya mereka bisa saling menanggapi. Ketik @nama di awal pesan untuk hanya menyapa satu anggota tertentu. Model yang tidak merespons saat chat berjalan akan otomatis dikeluarkan dari grup supaya cuma yang benar-benar aktif yang tersisa. Khusus mode diskusi: peran Notulen tidak ikut berdebat — dia cuma bikin ringkasan tiap putaran & kesimpulan akhir pakai model & namanya sendiri.
"Gratis" ditandai berdasarkan pola nama model & penyedia yang diketahui gratis (mis. berakhiran -free, atau via DuckDuckGo AI Chat) — bukan data resmi dari OmniRoute, karena API-nya tidak mengekspos status berbayar/gratis secara eksplisit. Semua tombol "Tambahkan" di atas menguji koneksi tiap model dulu (request kecil & hemat token) — yang tidak menjawab otomatis dilewati, tidak ikut ditambahkan. Model reasoning berat kadang butuh lebih banyak token untuk mulai menjawab, jadi sesekali bisa salah terdeteksi gagal padahal sebenarnya jalan — tinggal tes ulang manual di baris anggotanya kalau begitu.
